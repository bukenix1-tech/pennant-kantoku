# ⚾ ペナント監督

パワプロのペナントモードのように、球団の監督兼フロントとして 1 年ずつシーズンを戦い、
選手を育て、お金をやりくりして優勝を目指すブラウザゲームです。
HTML / CSS / JavaScript だけで動きます（インストール不要・ビルド不要）。

## 遊び方（VS Code で）

1. VS Code で `baseball` フォルダを開く（ファイル → フォルダーを開く）
2. **F5** を押す（「ゲームを Chrome で開く」/「Edge で開く」）→ ブラウザでゲームが始まる
   - もしくは、おすすめ拡張 **Live Server** を入れて、`index.html` を右クリック →「Open with Live Server」
   - もしくは、`index.html` をダブルクリックするだけでも動きます

セーブはブラウザ（localStorage）に自動で入ります。試合を進めるたびに保存されます。

### スマホで遊ぶ（どこでも）

スマホのブラウザで **https://bukenix1-tech.github.io/pennant-kantoku/** を開くだけで遊べます（パソコンは要りません）。
「ホーム画面に追加」すると、アプリのようにアイコンから開けます。一度開けば、電波がない所でも開けます。

ゲームを直したら、コミットして `git push` すると、1 分ほどでこのページにも反映されます
（`sw.js` の `CACHE` の番号を上げておくと、スマホに取っておいた古い分が確実に入れかわります）。

### スマホで遊ぶ（家の Wi-Fi）

1. パソコンで **`スマホで遊ぶ.bat`** をダブルクリック（黒い画面にアドレスが出ます）
2. スマホをパソコンと同じ Wi-Fi につなぎ、ブラウザでそのアドレス（例：`http://192.168.40.105:8000`）を開く
3. やめるときは黒い画面を閉じる

画面の幅が狭いと自動でスマホ用の見た目になります。セーブはスマホのブラウザに入るので、パソコンとは別のデータです。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 次の試合・前の試合のスコアと流れ・順位・ニュース |
| チーム | 全 12 球団の選手一覧（能力 S〜G・調子・成績・年俸）。名前を押すと詳細 |
| 一軍・二軍 | 支配下 70 人のうち一軍 29 人を決める（登録・抹消）。「おまかせ」もある |
| オーダー | 一軍の選手で打順・守備位置・先発ローテ・セットアッパー・抑えを決める。「おまかせ」もある |
| 練習 | 練習量（軽め / 普通 / 猛練習）と、選手ごとの練習の重点 |
| 日程 | これからの試合・結果・相手別の勝敗 |
| 順位・成績 | 順位表・個人成績トップ5・歴代の優勝 |
| 経営 | 収支・グッズ開発・施設の改修・助っ人外国人の獲得（チケット代は 4,000円で固定） |
| トレード | 他球団と選手を交換（7 月末まで ＋ オフのキャンプ前） |
| 自由契約 | 戦力外になった選手・独立リーグの選手と契約（オフの契約更改〜開幕前 ＋ シーズン中の 7 月末まで） |
| ドラフト候補 | 開幕のときに発表される今年の候補。☆で「気になる選手」に入れておける |

**2 リーグ 12 球団・143 試合**（同じリーグの相手と 25 試合ずつ ＋ 交流戦 18 試合）。3 月末の金曜に開幕し、月曜は休み。
レギュラーシーズンのあとは **クライマックスシリーズ（ファースト・ファイナル）→ 日本シリーズ**。
そのあとオフシーズン：**表彰 → FA → 契約更改（引退・年俸）→ ドラフト → キャンプ** と進み、
選手は 1 つ歳を取って次の年へ。何年でも続けられます。短い 83 試合・43 試合も選べます。

## しくみ

- 試合は 1 打席ずつ計算（ミート・パワー・走力・守備 と 球速・コントロール・変化球・スタミナ・調子・疲れ）。両リーグ DH 制
- 先発は 6 人ローテで中 6 日。リードした 8 回はセットアッパー、9 回は抑え。リリーフは 3 連投しない
- まれに選手が **覚醒** して大きく伸びる（若くて才能★の多い選手ほど起きやすい。キャンプはチャンス）
- 若い選手と才能（★）のある選手は練習でよく伸び、ピークを過ぎると衰える（早熟・普通・晩成）
- 入場料はほぼ決まった収入（球場の大きさで決まり、ファンの数で少しだけ増える）。グッズを作らなくても黒字になる程度
- グッズは選手の **人気度**（活躍で上がり、活躍しないと下がる）と **ビジュアル**（★1〜5、生まれつき）で売れ行きが変わる。
  出たばかりがいちばん売れ、だんだん飽きられる。選手が移籍・引退すると販売終了
- 支配下は 70 人まで、一軍は 29 人まで（外国人は一軍に 4 人まで）。シーズン中に抹消した選手は 10 日間一軍に戻せない。
  ケガをした一軍の選手は自動で抹消され、二軍から代わりが上がる。二軍の 25 歳以下は二軍戦の経験で少し伸びやすい。ドラフトは 7 巡目まで
- 自分の選手を自由契約（戦力外）にできるのは **オフの契約更改〜開幕前だけ**。出した選手は自由契約選手になり、他球団に拾われることもある
- **FA**：一軍登録の年数が高校出身 8 年・それ以外 7 年で FA 権（再取得は 4 年）。忠誠心が高いほど・地元の球団ほど残りやすい。
  宣言した選手には各球団が年俸と年数を提示し、選手が選ぶ。A・B ランクを取ったら元の球団に補償金。複数年契約の間は年俸固定
- **二刀流**：投手と野手の両方の能力を持つ選手。リーグに最初から 2 人、ドラフト候補にもまれにいる。27 歳以下なら挑戦させることもできる
- **天才**：まれにいる、伸びが段ちがいの選手。ドラフトではスカウトの講評に「天才肌」と出ることがある（段階が低いと見間違いも）。自分のチームで 1 年たつと分かる
- **スカウト**：見立てのずれは段階で小さくなる（Lv1 ±15 → Lv5 ±1）
- **セーブ**：3 つのスロット。上書きや削除の前に確認が出る。別スロットへのバックアップもできる。
  **ファイルに書き出し・読み込み**ができるので、ブラウザのデータを消しても戻せる（パソコンとスマホの間で移すのにも使える）。
  開いたときに、ブラウザへ「データを勝手に消さないで」と頼む設定も入れている（ブラウザによっては使えない）
- 順位・成績の画面で、過去の年の最終順位が見られる
